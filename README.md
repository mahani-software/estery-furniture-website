# Estery Furniture Showcase

I want a very good professional website for a business dealing in furniture and furniture accessories in Kampala. Find many beautiful images online and use them, make each image on the site clickable to take to the details page. The name of the company is ESTERY FURNITURE You may also The home page should be able to show a big company logo, not only in the top bar. The site should have many pages, use tanstack router for routing. Use javascrip React Vite, not Typescript. Please make sure the images are very many and very impressive
